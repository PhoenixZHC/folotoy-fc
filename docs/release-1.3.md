# FC模拟器 1.3 交付（2026-10-10）

> 当前 FC 1.5 完整包与设备身份见 [交付说明](release-1.5.md)，验收边界见 [验证记录](validation.md)。本页版本、哈希和测试结论保留其历史时点或专题范围。

本版修复 Wi-Fi 管理后因堆碎片导致的游戏启动失败，以及大 ROM 首次启动时 I2S DMA 分配失败。使用分块帧缓冲、固定音频资源、提前准备音频设备和复用动画缓冲。固件和网页版本同步为 1.3，Mapper 4 PRG 上限保持 1.5 MiB。

## 完整包

- 本地文件：`deliverables/FC-1.3-16games/FC-1.3-16games-full.bin`
- 大小：8,388,608 字节（8 MiB）；ESP32-C3 / 8 MiB Flash；写入地址 **0x0**。
- 完整写入会覆盖设置、游戏和存档，请先备份需要保留的数据。
- 沿用 1.2 正式包原 16 款 ROM，ROM 分区逐字节一致；未加入诊断用口袋妖怪 ROM。历史包保留。
- 同目录保留 ELF、MAP、sdkconfig、组成镜像、打包清单、校验报告和许可证。

## 验证与边界

ESP-IDF 5.5.3 正式构建通过；应用 2,524,608 字节，未超出 3 MiB 分区。镜像布局、读回一致性、应用与 ELF 身份、内嵌版本 1.3、16 款 ROM 和诊断开关关闭均已校验。打包测试 7 项通过、0 失败。

修复代码已有 15 组主机测试通过、0 失败；COM14 冷启动先开关 Wi-Fi、再优先启动大 ROM 的 40 次启动链检查和 4 次 Wi-Fi 启停通过。用户确认口袋妖怪运行及暂停恢复正常。该实测针对标记 1.2 的修复候选应用；本轮仅升级版本、网页标识及交付记录，未重复这组功能测试。

**1.3 完整包尚未烧录设备**。实际 HTTP 上传/删除全流程、长期运行、全部 ROM 及外设组合未在本轮重新验收。本轮不提交或推送 GitHub。详细修复证据见 [回归记录](wifi-memory-regression.md)。
