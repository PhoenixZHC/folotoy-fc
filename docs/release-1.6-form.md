# FC 1.6 使用方法与表单文案

[English](release-1.6-form.en.md) · [完整交付与验证边界](release-1.6-orientation.md)

## 使用方法

### 一、首次使用

开机后使用机身上下键选择菜单，OK确认。预装游戏无需联网。手柄、BLE蓝牙键盘和兼容遥控器均从主页“连接手柄”入口配对：先让外设进入配对状态，再选择对应设备。

### 二、使用手柄

如果手柄在X-Box模式下无法被识别或连接，可以尝试切换到安卓模式，重新进入配对状态后连接。Q36使用D档，选择“Q36 for Android”；具体切换方法参考手柄说明书。本设备支持兼容的BLE手柄，不支持经典蓝牙，并非所有安卓模式都兼容。

连接后进入“手柄测试”检查方向、A/B、Start、Select、组合键和释放。用方向键选择游戏、A确认启动、Start开始；游戏中十字键或左摇杆控制方向，A/B执行动作，Select用于游戏选择。长按Select约1秒暂停，在支持返回的菜单页长按Select可返回。

### 三、使用蓝牙键盘

让兼容的BLE键盘进入配对状态，在“连接手柄”列表中选择键盘；如出现配对码，按屏幕提示操作。

W=上、S=下、A=左、D=右；J=游戏A、K=游戏B、I=Select、L=Start。可用机身按键选择游戏、OK启动，进入游戏后按L开始。游戏中用WASD移动，J/K执行动作，I用于选择。长按I约1秒暂停，在支持返回的菜单页长按I可返回。

### 四、使用蓝牙遥控器

目前已验证小米RC001、固件2671的单键操作，其他型号不保证相同映射或兼容。按遥控器说明书进入配对状态，从“连接手柄”列表选择对应遥控器。

横握映射以遥控器原有箭头为准：右→游戏上，上→游戏左，左→游戏下，下→游戏右；TV=游戏A/菜单确认，三横线菜单=游戏B，主页=Start，返回=Select。中央OK未映射，请使用TV确认。

用映射后的方向选择游戏、TV启动、主页开始。长按返回约1秒暂停，短按保留Select功能。该实物不能可靠同时移动和射击，需要组合键的动作游戏建议使用手柄。

### 五、暂停与游戏方向

机身长按OK也可暂停。暂停菜单可继续、同步电池存档、设置、息屏、退出或切换方向。方向依次为竖屏→横屏→横屏翻转→竖屏，继续游戏后生效。普通横屏逆时针横握，翻转顺时针横握。仅游戏画面旋转，所有菜单仍竖屏，按键映射不变。

### 六、默认游戏方向

主页“设置”可保存默认方向，重启后仍有效，下次启动游戏时使用；初始竖屏。暂停菜单临时切换不修改默认值。

### 七、游戏管理与存档

进入“游戏管理”，连接热点folotoy-fc（无密码），浏览器打开 http://192.168.4.1/，无互联网提示时保持连接。最多16个游戏，按网页提示管理自己的.nes文件。支持电池存档的游戏先使用游戏内存档，再在暂停菜单同步；不支持任意位置即时存档。

完整BIN从 **0x0** 安装会覆盖游戏、存档、设置和配对，并非保留数据的增量升级。

## 1.6 更新日志

1. 新增对部分手柄安卓模式的兼容支持，修复可以搜索到手柄、但连接长时间等待或提示“连接较慢，请重试”的问题。X-Box模式无法识别或连接时，可尝试切换到安卓模式重新配对。
2. 新增游戏画面方向切换，支持竖屏、横屏和横屏翻转，可在暂停菜单中切换，继续游戏后生效。
3. 系统设置新增默认游戏方向，保存后重启仍有效；初始默认竖屏，暂停菜单中的临时切换不影响默认设置。
4. Q36安卓模式，以及良值口袋手柄迷你、口袋手柄Pro的安卓和Xbox模式已通过本轮用户实测；三种画面方向及默认保存也已通过测试。

手柄兼容范围以实际型号、固件和BLE协议为准，不代表支持所有安卓模式或经典蓝牙手柄。
