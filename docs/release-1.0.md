## 游戏与空间

魂斗罗、超级马里奥兄弟、坦克大战、F-1赛车、双截龙、热血足球、炸弹人、俄罗斯方块、武林外传、星之卡比、忍者神龟2、洛克人3、吞食天地、松鼠大作战2、冒险岛、忍者特训。

16/16 槽；游戏数据使用 4,177,920/4,182,016 字节，剩余 4 KiB，独立 960 KiB 存档区。电池 SRAM 双副本，不提供即时存档。原文件名和 ROM 哈希见 `selection-full16.json`；所有游戏来自用户本地 ROM。

## 验证及未完成项

8 组主机、5 项打包、6 项模拟入口通过；八款核心前后对比各 3,600 帧画面/音频一致，16 款烟测各 3,600 帧运行结束且有画面。应用与游戏包已分别在 COM14 校验写入；启动 games=16。完整组合镜像经打包回读、分区组件及 ELF 身份核验；未再整包覆盖设备。

最后一轮七款真机显示 13.9–19.6 fps；卡比和忍者特训仍低于 15，武林/卡比各记录 3 次音频块丢弃。无 panic/assert。新游戏保存/读档、物理断电、完整 BLE/Wi-Fi 和长期稳定性仍待验收，不称为全部通过的稳定发行版。详见项目 `docs/performance.md` 与 `docs/validation.md`。
