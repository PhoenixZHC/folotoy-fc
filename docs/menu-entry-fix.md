# 已连接入口与游戏列表持键修复（2026-10-14）

[English](menu-entry-fix.en.md)。

## 用户要求与行为

- 未连接：主页第一项显示 **连接手柄**，进入现有配对页，仍支持 BLE 键盘。
- 已连接：第一项显示 **游戏列表**，直接进入游戏列表；从列表回主页再点此项，只展示列表。
- 蓝牙断开：主页及时恢复 **连接手柄**。在列表中断开则返回主页，空列表同样处理。

原行为中主页固定写“配对键盘或手柄”；已连接时配对循环立即结束并进入列表。列表的 A 键基线初始化为 false，因此主页用于确认的同一次 A 持键被当成列表的新确认，直接启动首个游戏。

修复使主页文字随连接状态重绘，入口在连接时跳过配对流程。列表复用已有菜单边沿状态机，以入页当前持键建立基线并清理机身旧事件，须释放后新按 A/OK 才启动游戏；从游戏返回列表同样重新建立基线。原长按 OK/Select 返回保持。

## 验证与交付

26 组主机测试通过、0 失败，覆盖真实主页/列表函数中的标签切换、连接/配对路由、入页持 A、释放后确认、游戏返回持键、方向入页基线及断连返回。新增测试最初缺少测试桩的 stdio 头，补齐后重跑通过，其他 25 组同一代码状态的通过结果复用。

ESP-IDF 5.5.3 正式构建、应用/ELF 与完整镜像校验通过；三个诊断开关均关闭。保留固定完整手柄测试页及已通过实物单键验证的 RC001 报告修复，多键限制不变。详见 [RC001 记录](rc001-input-fix.md)。
