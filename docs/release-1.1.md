## 改动与验收范围

相对历史 1.0 完整包，增加短按有界状态队列、HID 按 Report ID 独立保存并合并状态、真实描述符解析、连接恢复与广播识别保护，以及左摇杆映射。保留 FC 核心、显示、音频与分区布局。详见 [架构](../ARCHITECTURE.md) 与 [验证](validation.md)。

14 组主机、5 项打包测试通过；正式构建、完整镜像分区布局、各组件摘要、应用与 ELF 身份及版本 1.1 校验通过。`FC_SIM_TEST` 和 `FC_INPUT_TRACE` 均关闭。

用户实测对象是本次修复后仍标 1.0 的应用，已仅写入 COM14 的应用分区并校验；180 秒串口观察记录了魂斗罗/马里奥运行，无输入丢弃或崩溃日志。用户随后确认实际测试无明显问题。1.1 是仅改版本标识后的重新构建，不能称作新二进制已再次真机验证。详见 [设备记录](device-1.1.md)。

预装游戏、空间和历史逐款证据见 [16 款清单](games-full16.md)。历史部分场景低于 15 display_fps、少量音频丢块，以及键盘/其他手柄、完整按键矩阵、反复重连、存档与真实断电恢复、Wi-Fi 和长期稳定性，不因本次用户反馈标成全部验收。
