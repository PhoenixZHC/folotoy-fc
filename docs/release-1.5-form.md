# FC 1.5 表单文案

[English](release-1.5-form.en.md)。对应当前菜单修复日常版；固件身份见 [完整交付](release-1.5.md)。

## 中文使用方法

```text
1. 首次准备
安装固件后开机，准备兼容的 BLE 手柄或蓝牙键盘。设备不支持经典蓝牙手柄。玩预装游戏不需要连接 Wi-Fi 或互联网。
机身上、下键移动菜单选项，OK 键确认。

2. 连接输入设备
在主页选择“连接手柄”，让手柄、键盘或遥控器进入蓝牙配对状态，再用机身按键选择列表中的设备并确认。
良值 L1241 请使用 PC 无线模式，选择“IINE GAMEPAD”；出现固件版本确认提示时，按屏幕说明操作。键盘如出现配对码，也按屏幕提示完成。

3. 检查按键
连接后可进入“手柄测试”，检查方向和按钮是否正常响应、松开后是否恢复。
所有设备使用同一个完整测试页；遥控器或键盘没有的摇杆、肩键、扳机等不响应属于正常现象。

4. 开始游戏
连接成功后，主页第一项变为“游戏列表”。进入列表，选择游戏并按 A 或机身 OK 启动；使用手柄 Start 开始游戏。
键盘操作：WASD=方向，J=A，K=B，I=Select，L=Start。

5. 小米遥控器横握操作
方向按遥控器原有图标对应：右→游戏上，上→游戏左，左→游戏下，下→游戏右。
TV=A，三横线菜单=B，主页=Start，返回=Select。菜单确认使用 TV 键；遥控器中央确认键未映射。
已验证 RC001、固件 2671 的单键操作。该遥控器不能同时移动和射击，需要组合键的游戏建议使用手柄。

6. 暂停与返回
游戏中长按 Select 约 1 秒打开暂停菜单，可继续游戏、调整设置或退出。机身长按 OK 也可暂停。
小米遥控器长按返回键对应此操作；短按仍是游戏 Select。进入或恢复页面后，先松开再重新长按。

7. 管理游戏
需要更换游戏时，进入主页“游戏管理”。用手机或电脑连接热点“folotoy-fc”（无密码），在浏览器打开 http://192.168.4.1/。
提示“无互联网”时保持连接，按网页提示管理自己的 .nes 文件。最多 16 个游戏，预装版已占满槽位，更换时需先腾出空间。

完整 BIN 从 0x0 烧录会覆盖原游戏、存档、设置和蓝牙配对；它不是保留数据的增量升级包。
```

## 中文更新日志

```text
1. 新增小米 BLE 遥控器横握映射：旋转方向键，TV 键对应 A，菜单键对应 B，主页键对应 Start，返回键对应 Select。
2. 修复小米 RC001 遥控器连接成功后，所有按键无响应的问题。
3. 恢复统一的完整手柄测试页，手柄、键盘和遥控器共用；设备没有的按键、摇杆和扳机保持不响应。
4. 优化主页入口：已连接时显示“游戏列表”，蓝牙断开后恢复“连接手柄”。
5. 修复从主页再次进入游戏列表时，确认键尚未松开导致自动启动第一个游戏的问题。
6. 提供保留原 16 款预装游戏的完整安装包，关闭输入诊断日志。

已验证 RC001（固件 2671）的单键操作正常；该遥控器不能可靠同时输入多个按键，不适合需要边移动边射击的游戏。
```
