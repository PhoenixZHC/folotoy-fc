## 真机验证

COM14 应用及游戏分区分别写入，设备 Hash 校验通过。安装 16 款前备份原 ROM/存档，写后存档区摘要与备份一致；启动 FC_READY version=1.0 games=16，ELF 前缀 e206f48c3 匹配。最后一轮用户游玩七款，显示 13.9–19.6 fps，完整表见 [性能记录](performance.md)。无 panic/assert；武林外传、卡比各累计 3 个音频块丢弃，最长等待约 170 ms。测试结束后端口正常关闭。

用户较早确认整体明显提升和音频总体流畅；最后一轮仅回复测试结束，没有逐款主观听感或保存成功反馈。不得把计数器、输入变化或启动成功替代用户对画面/音质/存档的验收。
